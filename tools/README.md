# tools/README

This branch groups a subset of the repository into categorized folders.

- tools/benign/: small utilities and harmless scripts copied for convenience
- tools/termux/: Termux setup and installer scripts copied here
- tools/misc/: miscellaneous non-destructive scripts
- duplicates/: exact or near-duplicate files moved here for review

Notes:
- No original files were modified or deleted on the default branch.
- "Dark" tools (phishing, DDoS, flooders, stressers) were left in place per instructions.
- This is a non-destructive reorganization: files are copied, not moved. Inspect duplicates/ if you want deletions.
